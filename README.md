# Datheon Data Analytics & Power BI Internship

Data analytics projects from the Datheon Data Analytics & Power BI Internship.

I'm Lilit, a Computer Science graduate from the American University of Armenia. This repository holds the four projects I completed during the internship, covering exploratory analysis in Python, interactive dashboards in Power BI, and customer retention analytics. Each project folder has its own README with the business problem, methodology, results and recommendations.

## Projects

| # | Project | Tools | Key finding |
|---|---------|-------|-------------|
| 1 | [Superstore Retail Sales EDA](01_Superstore_EDA) | Python, Pandas, Seaborn | Discounts above 20% apply to 14% of line items but lose about $135K, erasing roughly a third of the profit earned elsewhere. |
| 2 | [Executive Sales & Profit Dashboard](02_PowerBI_Dashboard) | Power BI, DAX, Power Query | A two-page star-schema dashboard showing that Furniture brings in 32% of sales but only 6% of profit. |
| 3 | [Customer Cohort and Churn Analytics](03_Customer_Churn_Analysis) | Python, Pandas, Plotly | Baseline churn is 26.5%, and one segment (25.5% of customers) accounts for 55.3% of all churn. |
| 4 | [Corporate Financial & Margin Performance Dashboard](04_Financial_Performance_Dashboard) | Power BI, DAX, financial modeling | A three-page dashboard with income statement waterfall, budget variance and scenario sliders, showing that COGS consumes about 86% of net sales. |

## Repository structure

- `01_Superstore_EDA/`: Python exploratory analysis
- `02_PowerBI_Dashboard/`: sales and profit dashboard
- `03_Customer_Churn_Analysis/`: cohort and churn analytics
- `04_Financial_Performance_Dashboard/`: financial and margin dashboard


Each folder contains the notebook or `.pbix` file, the data, screenshots, and a README. The Power BI projects also include an exported PDF, so the reports can be read without Power BI Desktop.

## Notes

The datasets are public sample datasets (Superstore, IBM Telco Churn, Microsoft Financial Sample), so the findings are practice results and not real business results.
